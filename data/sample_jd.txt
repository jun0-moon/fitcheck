[가상테크] AI 서비스 개발자 (신입)

우리는 기업용 문서 검색 서비스를 만드는 가상의 스타트업입니다.

주요 업무
- LLM API를 활용한 문서 요약·질의응답 기능 개발
- 사내 문서 검색(RAG) 파이프라인 설계 및 운영
- 서비스 백엔드 API 개발 및 배포

자격 요건
- Python 기반 개발 경험
- REST API 설계 및 개발 경험
- Git을 이용한 협업 경험

우대 사항
- LLM API(OpenAI, Gemini 등)를 이용한 프로젝트 경험
- 벡터 DB 또는 임베딩 검색 경험
- Docker 및 클라우드 배포 경험
